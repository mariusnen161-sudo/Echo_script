ЗАМЕНА БАННЕРА НА КАРТИНКУ

1. На GitHub в Echo_script нажмите Add file → Upload files.
2. Загрузите banner.png из этой папки в корень репозитория рядом с
   auto-start-standalone.lua. Нажмите Commit changes.
3. Замените код auto-start-standalone.lua обновлённой версией и сохраните.
4. Запустите прежнюю однострочную ссылку в Madium.

banner.png — ваша исходная noFilter.webp, преобразованная в PNG без изменения
рисунка. Изображение заполняет широкий баннер, поэтому верх и низ обрезаются.
Для показа картинки целиком в gui-theme.lua можно поменять ScaleType.Crop
у BannerPhoto на ScaleType.Fit: появятся поля по бокам.

Для показа локальной картинки исполнитель должен поддерживать writefile
и getcustomasset (или getsynasset). Если они недоступны или картинка не
загрузилась, остаётся прежний баннер; фарм продолжает работать.
